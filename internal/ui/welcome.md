# manul

> A grumpy little browser for the markdown web.

No HTML. No CSS. No JavaScript. Just markdown, rendered *your* way —
the same on every site.

A growing part of the web publishes agent-readable markdown alongside
HTML: an `/llms.txt` index at the root and `.md` twins of each page.
That content is fast, light, and free of trackers and ads. It was made
for machines, but it is the web many humans wished they had.

## How to browse

Every link on a page gets a number — like the links below.

- `Tab` selects the next link, `Shift+Tab` the previous one.
- `Enter` follows the selected link.
- Or type a link's number, then `Enter` (watch the statusbar).
- `:` opens any URL or bare domain — manul finds its markdown twin.
- `Backspace` goes back, `]` forward, `s` returns to this page.
- `?` shows every key.

Try it now: press `Tab` to select a link below, then `Enter`.
